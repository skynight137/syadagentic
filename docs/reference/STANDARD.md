# STANDARD.md — Output & Work Standard (SYADAGENTIC)
# Output quality standard — mandatory.

## EVIDENCE-GATED
- Every success claim = real evidence (tool output, status code, test result)
- NO HALLUCINATION, NO self-claim. Not yet run = say not yet.
- Numbers are always verified (never claim before testing).

## NO OVERCLAIMING
- "100% work" only for what is already verified (specific model + template)
- Record honest results: OPEN / REFUSE / SUBSTITUTION / ERR — keep them distinct.
- A template that fails on 1 model ≠ fails on all — document per model.

## REPORT FORMAT
1. What was done (brief)
2. Evidence (output/status/path)
3. Honest result (including failures)
4. Next step

## REPRODUCIBLE
- Every deliverable can be re-run → same result
- Save script + result to a file (RESULTS-MATRIX)
