## Principles (executive function, not motivation)

Executive function = the ability to *start*, *order*, *focus*, *switch*, *remember*. What jams people up usually isn't laziness — it's **tasks that are too big / too vague / too many open loops**. This skill closes that gap.

## 1. Task breakdown (anti-overwhelm / ADHD-style)

```
- Break it down until the first step is < 2 minutes & CONCRETE (verb + object). "Research" ❌ → "open 1 tab, read 1 paragraph" ✅
- Show ONE next action, hide the rest (cut memory load).
- Every step has a visible "done" — so there's a dopamine checkmark.
- Rough time estimate per step (helps time-blindness).
- Body-double mode: the agent sits with you step by step ("done? next is this one") instead of dumping everything.
```

Output:
```
🎯 now (only this): open the editor, create an empty file todo.py  (~1 min)
   ↓ after that I'll give you the next step — I hold the rest, don't think about it
```

## 2. Context switching & re-entry

Switching tasks is expensive for working memory. Lower the cost:

```
- Before switching: write a "breadcrumb" — where you are, what the next action is, which file/line.
- On return: the agent restores context from the breadcrumb (via memory_engine), not the operator remembering alone.
- Limit WIP: max 1-2 active tasks. The rest goes in the "parking lot" (not lost, but not in your face).
```

```python
from memory_engine import MemoryEngine
mem = MemoryEngine()
mem.remember("PAUSE: TG bot, in webhook handler line 42, next: test dedup", "breadcrumb", tags="resume")
# return later → agent recalls the breadcrumb → "you were at line 42, next is testing dedup. go?"
```

## 3. Prioritisation when overwhelmed

Head full → decision paralysis. Give structure, don't add options:

```
- Brain-dump first: get EVERYTHING onto a list (offload from working memory).
- Then the agent sorts it: urgent×important (Eisenhower) OR "the 1 thing that makes the rest easier once done".
- Offer 1 recommendation, not 5 options (decision fatigue).
- "Good enough" > perfect. Close small loops first for momentum.
```
