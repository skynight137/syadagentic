## 1. Compliance & regulatory review

Systematic check against the relevant frameworks (GDPR, SOC2, PCI-DSS, HIPAA, etc.) — per the operator's context, not all at once.

```
1. SCOPE     → what data is touched? (PII, cards, health) → which frameworks apply
2. CHECKLIST → control mapping: data retention, consent, encryption at-rest/in-transit, access, audit log
3. GAP       → what's missing / half-done → rank by risk
4. REMEDIATE → concrete recommendations + implementation examples (complement to sk16)
```

Output: a gap list + fixes, NOT a "compliant" stamp. Flag which items need human legal review.

## 3. Deploy pipeline & CI/CD

Automate build → test → (gate) → deploy. Generate the workflow per platform:

```yaml
# .github/workflows/ci.yml — general pattern (adjust)
on: [push, pull_request]
jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - run: <install deps>
      - run: <lint>
      - run: <test>            # MUST be green before deploy
  deploy:
    needs: test
    if: github.ref == 'refs/heads/main'
    runs-on: ubuntu-latest
    steps: [ ... ]             # deploy to VPS (sk2) / registry
```

Principles: test gate before deploy (never deploy red), secrets via CI secrets not hardcoded, rollback plan. Deploying to prod = outward action → if via the agent, R9 gate. Combo sk2 (VPS target), sk16 (build).

## 4. Code-migrator (porting between languages/frameworks)

Port code between languages (Python↔TS↔Go) or frameworks (Express→FastAPI, Flask→Django):

```
1. INVENTORY → map modules, dependencies, language features with no 1:1 match
2. IDIOM      → port to the target IDIOM, not transliteration (Pythonic ≠ Go-ish)
3. TEST-FIRST → port tests first / write characterization tests → becomes a regression net (combo sk56/sk26 TDD)
4. RISK        → flag parts with different semantics (async model, error handling, types, concurrency)
5. INCREMENTAL → migrate gradually + run in parallel, never big-bang
```

What's fatal: a port that *looks* right but differs in semantics (e.g. integer overflow, timezone, floating point, null vs undefined). Flag it explicitly, don't stay quiet.
