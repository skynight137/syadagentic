## 1. Copywriting frameworks (use the one that fits, not at random)

| Framework | Structure | When |
|---|---|---|
| **AIDA** | Attention → Interest → Desire → Action | ads, landing, sales post |
| **PAS** | Problem → Agitate → Solution | pain-driven, cold audience |
| **BAB** | Before → After → Bridge | transformation, testimonial |
| **4P** | Promise → Picture → Proof → Push | email, long-form sales |
| **CHEF** | Clear · Honest · Engaging · Fitting | quality filter for all copy |
| **70-20-10** | 70% value · 20% curated share/promo · 10% selling | content mix ratio |

```
PAS example (cold):
P: "Your posts are good but nobody buys."
A: "Every day it scrolls past, your effort is wasted, the competitor wins."
S: "The problem isn't the content — it's the hook & CTA. Here's how to fix it: ..."
```

Pick the framework from the goal and audience temperature (cold/warm/hot), not from habit. One piece of copy = one dominant framework.

## 2. SEO-optimized writer

```
1. KEYWORD   → primary + secondary + long-tail (intent: informational/transactional/navigational)
2. STRUCTURE → keyword in title, H1, first paragraph, 1-2 subheadings, natural in body
3. ON-PAGE   → meta description (≤155 char) + alt text + internal link + clean slug
4. READABLE  → still write for humans first; keyword stuffing = penalty and bad to read
```

For captions/blogs: natural keywords, never sacrifice readability for the machine. E-E-A-T: show experience and proof.

## 3. Storytelling & narrative

```
HOOK → STAKES → STRUGGLE → SHIFT → TAKEAWAY
("this happened" → "why it matters" → "the hard part" → "turning point" → "what you take from it")
```

Story > list of facts: specific (numbers/names/moments), one dominant emotion, personal touch (your point of view). Avoid generic — concrete detail is what sticks. End with one lesson the reader can use.

## 4. Multilingual & localization (including RTL)

Localization ≠ translation. Adapt meaning, idioms, cultural references, formats (date/currency/units):

```
- Idioms & humor → find the cultural equivalent, never literal
- RTL (Arabic/Hebrew/Farsi/Urdu) → text direction, alignment, mirrored UI, numerals
- Tone per culture → formal vs casual norms differ per language/region
- CTA → match local expectations, not a literal translation
```

Indonesia: respect the operator's style (USER.md) — `lo/gue` vs `kamu` vs regional. Keep technical terms as-is (don't translate "deploy", "swap").
