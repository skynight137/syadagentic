## 1. ComfyUI advanced workflow (API mode)

ComfyUI headless = a node-graph JSON POSTed to `/prompt`. Don't click the UI; drive it via the API so it stays reproducible and batch-able.

```python
# pip install httpx
import httpx, json, time, uuid

COMFY = "http://127.0.0.1:8188"

def run_workflow(graph: dict, timeout=300) -> list[str]:
    """POST graph JSON (exported via 'Save (API Format)' from ComfyUI), poll history, return file paths."""
    cid = uuid.uuid4().hex
    r = httpx.post(f"{COMFY}/prompt", json={"prompt": graph, "client_id": cid}, timeout=30)
    r.raise_for_status()
    pid = r.json()["prompt_id"]
    t0 = time.time()
    while time.time() - t0 < timeout:
        h = httpx.get(f"{COMFY}/history/{pid}", timeout=15).json()
        if pid in h:
            outs = []
            for node in h[pid]["outputs"].values():
                for img in node.get("images", []):
                    outs.append(f"{COMFY}/view?filename={img['filename']}&subfolder={img.get('subfolder','')}&type={img['type']}")
            return outs
        time.sleep(1.5)
    raise TimeoutError(f"workflow {pid} > {timeout}s")
```

Pattern: export the graph from ComfyUI via **Save (API Format)**, store it as a template, then patch the nodes that need it (prompt text, seed, model) before POSTing. Batch = loop seeds via sk12 (`p-limit`/concurrency). Heavy GPU → run ComfyUI on a GPU VPS, drive it from the agent over an SSH tunnel.

→ Reference workflow templates & node patching helper: `scripts/scene_prep.py` (also used by sk19 for 3D scenes).

## 2. Manim — math/explainer animation

```python
# pip install manim   (needs ffmpeg + LaTeX for math text)
from manim import *
class Explain(Scene):
    def construct(self):
        eq = MathTex(r"e^{i\pi} + 1 = 0")
        self.play(Write(eq)); self.wait(1)
        self.play(eq.animate.to_edge(UP))
        self.play(Create(Axes(x_range=[-3,3], y_range=[-2,2])))
```
Render: `manim -qm scene.py Explain` (`-qm` medium, `-qh` high, `-ql` fast draft). Output `media/videos/.../Explain.mp4`. For technical concepts a step-by-step animation sticks better than text. Pair with sk3 (voiceover script).

## 3. Excalidraw — hand-drawn diagram

Excalidraw = JSON `{type:"excalidraw", elements:[...]}`. Generate it programmatically for architecture/flows instead of drawing by hand:

```python
def excalidraw_box(x, y, w, h, text, eid):
    rect = {"type":"rectangle","id":eid,"x":x,"y":y,"width":w,"height":h,
            "strokeColor":"#1e1e1e","backgroundColor":"#a5d8ff","roughness":1,"seed":1}
    label = {"type":"text","id":eid+"_t","x":x+12,"y":y+h/2-10,"text":text,
             "fontSize":16,"containerId":eid,"seed":2}
    return [rect, label]
# chain boxes + arrows → {"type":"excalidraw","version":2,"elements":[...]}
```
Save `.excalidraw` → open it on excalidraw.com / VS Code plugin → export SVG/PNG. Good for system architecture diagrams (e.g. visualising the AGENTS.md router).

## 4. ASCII / retro video

```bash
# image → colour ASCII
chafa input.png --size 80x40
# video → ASCII playback (terminal)
ffmpeg -i clip.mp4 -vf fps=12,scale=120:-1 frames/%04d.png && for f in frames/*.png; do chafa "$f" --size 120x50; sleep 0.08; clear; done
# render back to retro MP4 (CRT vibe): ffmpeg + curves/noise filter
ffmpeg -i clip.mp4 -vf "curves=preset=vintage,noise=alls=8:allf=t" retro.mp4
```

## 5. Web design systems (Stripe / Linear / Vercel vibe)

Don't reinvent — use battle-tested design tokens. Cluster to sk9 for React/Tailwind implementation.

| System | Visual signal | Core tokens |
|---|---|---|
| Stripe | soft gradient, depth, trust | indigo `#635bff`, soft shadow, 8px grid |
| Linear | dark-first, crisp, fast | `#5e6ad2`, mono accents, 1px borders |
| Vercel | mono B/W, geometric | pure black/white, Geist font, harsh contrast |

Output design token JSON → feed to sk9 for components.

### Aesthetic judgment & design approval
Before saying "looks good", run the checklist — no blind ACC:

```
✅ Clear hierarchy? (the eye knows what to look at first)
✅ Consistent spacing? (4/8px grid, not random numbers)
✅ Enough contrast? (text is readable, WCAG AA)
✅ ≤2 typefaces, ≤1 dominant accent colour? (restraint > busy)
✅ Tidy alignment? (no "floating" elements)
✅ Passes the squint test? (squint, the structure still reads)
```
Something fails → point at the specifics + the fix, not just "feels flat". Approval that is final and irreversible (publish/print) → operator sign-off (sk58).
