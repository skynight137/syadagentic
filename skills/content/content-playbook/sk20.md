Turn "AI-smelling" text into a natural human voice, and adapt it to a specific brand voice. **Optional, keyless, not a funding path.** Tool: `scripts/humanizer.py` (deterministic rewriter + AI-tell detector).

> Being honest up front: "humanizer" is **not** a tool for fooling academic/plagiarism detectors. It exists to make your writing sound like you — not to pass off someone else's/AI's work as human where that's forbidden. Use it for marketing, content, email, brand — not for exam cheating.

---

## AI tells to kill

Patterns that make text read as "written by AI". The detector in `humanizer.py` flags these:

| Tell | Example | Replace with |
|---|---|---|
| Cliché hedging | "It's important to note that…" | delete, go straight to the point |
| Forced tricolon | "fast, reliable, and scalable" | 1-2 traits that actually matter |
| Stiff transitions | "Moreover, Furthermore, In conclusion" | natural connectors / a full stop |
| "Delve / leverage / robust / seamless" | corporate jargon | everyday words |
| Perfect symmetry | every paragraph the same length | vary sentence rhythm |
| Em-dash flood + "not only…but also" | — | split, simplify |
| Empty closer | "In summary, …", "Hope this helps" | cut it entirely |
| Neutral with no stance | no opinion/risk | take a position, admit the trade-off |

## Humanize principles (in priority order)

1. **Burstiness** — humans write a long sentence then a short one. AI is flat. Vary it.
2. **Specific > general** — numbers, names, concrete examples. "went up a lot" → "went up 3×".
3. **Stance** — have an opinion, admit uncertainty, name the trade-off. AI fences by default.
4. **Drop connectors** — "Additionally/Moreover/Furthermore" can almost always go.
5. **Voice, not politeness** — contractions, the occasional fragment, speaking rhythm. Not a formal essay.
6. **Cut the opening and the closer** — the first and last sentences are the most common AI filler.

## Usage

```python
from humanizer import score, humanize, to_brand
report = score(text)            # {ai_score: 0-100, tells: [...], suggestions: [...]}
clean  = humanize(text)         # deterministic rewrite: kills the tells that are safe to automate
# adapt to a specific brand voice (voice definition = dict)
out = to_brand(text, voice={"tone":"sharp","person":"first","forbid":["leverage","seamless"],"casual":True})
```

`score()` is deterministic (regex/heuristics, keyless) — for a quick check. Heavy rewrites (full restructure) still go through an LLM via `model_registry` (R7 cascade) with the brand voice as system prompt.
