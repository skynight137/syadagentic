## PART A: CONTENT CREATION (original m3)

### Interrupt Pattern Library

```
Gap:        "What [audience] doesn't know about [domain]..."
Reframe:    "Stop [accepted behavior]. Here's what works."
Proof:      "I did [outcome] in [window] using this:"
Method:     "How to [goal] without [friction]"
Index:      "[N] reasons [audience] fails at [goal]"
Arc:        "[Time ago] I was [state]. Today: [contrast]."
Position:   "Unpopular opinion: [defensible contrarian claim]"
Alert:      "If you're doing [behavior], stop. Here's why:"
Lossfear:   "[Audience] losing [thing] because of [unseen cause]"
Validate:   "[Specific number] of [audience] confirmed: [insight]"
```

### Delivery Frameworks

```
AIDA:    Interrupt → Qualify → Desire → Directive
PAS:     Specify Pain → Amplify → Resolve
STORY:   Baseline → Tension → Block → Resolution → Yield
PASTOR:  Problem → Amplify → Story → Transform → Offer → Response
4Ps:     Picture → Promise → Proof → Push
```

### Format Specifications

#### Short-form video (60–90s — TikTok, Reels, Shorts)

```
0–3s:    interrupt signal (hook + visual change)
3–15s:   qualification / context
15–50s:  core value delivery (numbered if 3+ points)
50–60s:  engagement directive (comment / follow / save)
```

#### Twitter/X thread (CT-style, crypto-aware)

```
Tweet 1: Interrupt (no thread emoji on tweet 1, controversial works)
Tweet 2–8: One proof point each (max 280 chars, keep punchy)
Tweet 9: Synthesis / "tl;dr"
Tweet 10: Directive (RT + follow + bookmark)
```

#### Long-form video (2–10 min)

```
0–30s:    interrupt → problem → "stick around for X"
30s–80%:  resolution + proof
80–90%:   validation (testimonial / data / case)
90–100%:  directive (subscribe + link)
```

#### Carousel (IG / LinkedIn)

```
Slide 1: Title + hook
Slide 2: Pain point
Slides 3–7: Method (one per slide)
Slide 8: Recap
Slide 9: CTA (save + share)
```

### Indonesian Voice Patterns (CT / kripto / casual)

```
- Use "lo/gue" for the CT vibe, "kalian" for a wider audience
- Crypto slang: gas, cuan, sultan, FOMO, ngegas, langsung gas, bagi-bagi, sat-set
```

### Content strategy builder

Before producing, settle the foundation (once, store it in the m15 vault, reuse):

```
PILLARS    → 3-5 core themes (e.g. education · behind-scenes · proof · opinion · CTA). Ratio 70-20-10.
AUDIENCE   → who, what problem, on which platform, in what language
POSITIONING→ 1 sentence: "for [audience] who [problem], I [unique solution]"
TONE       → take it from brand voice (m20) / USER.md
GOAL        → awareness | trust | leads | sales — different goal, different format
```

Output = a "content OS" that drives every later decision. Without it, content turns random.

### Platform-specific adapter

One message, different clothes per platform — do NOT copy-paste identically:

| Platform | Winning format | Length | Tone |
|---|---|---|---|
| **X/Twitter** | thread, punchy one-liner | short, hook in tweet 1 | fast, opinion |
| **LinkedIn** | thought leadership, story | medium, short lines | professional-personal |
| **Instagram** | carousel, visual-first | medium caption + hook | visual, relatable |
| **TikTok/Reels** | short video script | 15-60s, hook in first 3 seconds | energetic, native |

```python
from content import adapt
variants = adapt("your core message", platforms=["x","linkedin","ig","tiktok"])
```

### Viral hook & scroll-stopper

The hook is 80% of performance. Stop the scroll in 3 seconds / the first line:

```
HOOK PATTERNS:
- Contrast   : "Everyone says X. They're wrong."
- Numbers     : "3 mistakes that cost you..."
- Question : "Why does nobody see your posts?"
- Stakes     : "I lost $5k before I realised this"
- Curiosity gap: "Here's what nobody tells you about..."
```

The hook must be relevant to the body (clickbait that doesn't deliver kills trust). Clear CTA at the end: one action, not five.
