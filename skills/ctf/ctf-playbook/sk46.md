## RSA DECISION TREE (`rsa_attacks.py`)
- **small e (e=3)** + small msg → cube root (`small_e_root`).
- **e=3, same msg to 3 recipients** → Hastad broadcast (CRT + cube root).
- **N factorable** → factordb; close primes → Fermat (`fermat_factor`); small factor → Pollard.
- **Wiener** → small `d` (`wiener`, continued fractions).
- **common modulus** → same `n`, 2 coprime `e` → Bezout (`common_modulus`).
- **partial key / known high bits** → Coppersmith (Sage `small_roots`).
- **LSB/parity oracle** → binary-search decrypt.
- **p,q/phi known** → `decrypt_with_factors`.
```python
from rsa_attacks import auto, small_e_root, fermat_factor, wiener, common_modulus
m = auto(c, e, n)            # tries cheap attacks in order → plaintext int / None
```

## BLOCK CIPHERS
- **ECB** — identical block → identical cipher; cut-and-paste forge a token; byte-at-a-time decrypt against an oracle.
- **CBC bit-flip** — flip byte `C[i]` to control `P[i+1]` (auth bypass).
- **CBC padding oracle** — decrypt without the key when the server leaks pad validity.
- **CTR/stream nonce reuse** — XOR 2 ciphertexts → crib-drag.
- **GCM nonce reuse** — forge the tag (recover the auth key).
