## ANGR — primary automatic solver
Use when the binary validates input via branching (license/keygen/maze/constraint):
```python
import angr, claripy
p = angr.Project("./chal", auto_load_libs=False)
flag = claripy.BVS("flag", 8*32)
st = p.factory.full_init_state(stdin=flag)
for b in flag.chop(8): st.solver.add(b>=0x20, b<=0x7e)
sm = p.factory.simulation_manager(st)
sm.explore(find=lambda s: b"Correct" in s.posix.dumps(1),
           avoid=lambda s: b"Wrong" in s.posix.dumps(1))
print(sm.found[0].posix.dumps(0))
```
Tips: prefer `find=<success print addr>` over string match; use `avoid` to prune; state explosion → `veritesting=True` / hook expensive functions. Template: `scripts/ctf/templates/angr_solver_template.py` (3 modes: stdin/argv/blank-state).
