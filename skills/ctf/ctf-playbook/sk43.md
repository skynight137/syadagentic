# Category: Security

## SCOPE (read first)
Sub-skill for the **web** category in CTF/bug-bounty. Only runs **after sk32 + `scope_guard.py` confirms the target is in-scope** (whitehat line). Out-of-scope → R9 gate, hold. Exploitation runs inside the Docker sandbox (`scripts/ctf/sandbox`).

## TOOLBOX (in the sandbox)
- Intercept: mitmproxy/Burp · Content discovery: feroxbuster/ffuf/gobuster
- Light vuln scan: nuclei (verify manually) · Injection: sqlmap (`--batch` after manual confirmation)
- JWT: jwt_tool · Custom: Python `requests`/`httpx` (most solves = bespoke script)

## RECON (mandatory before exploit)
```bash
curl -sI "$TARGET"                 # header, cookie, CSP
whatweb "$TARGET" 2>/dev/null
feroxbuster -u "$TARGET" -w raft-medium-words.txt -x php,txt,bak,zip -q
curl -s "$TARGET/robots.txt"; curl -s "$TARGET/.git/HEAD"
```
If source is given (`app.zip`) → **read it first**, grep the sinks before fuzzing:
```bash
grep -rniE "system|exec|eval|pickle|yaml.load|render_template_string|jwt|md5|secret|query\(" .
```

## PLAYBOOK (ordered by CTF frequency)
- **SQLi** — bypass `' OR 1=1-- -`, UNION extraction, blind boolean/time. Hunt for a `flag` table.
- **SSTI** — test `{{7*7}}`/`${7*7}`. Jinja2 RCE: `{{ cycler.__init__.__globals__.os.popen('cat /flag').read() }}`.
- **SSRF** — internal svc, cloud metadata `169.254.169.254`, `file://`, `gopher://`.
- **IDOR / broken access** — iterate IDs, swap JWT `sub`, mass-assign `role=admin`. Check the multi-user app first.
- **JWT** — `alg:none`, weak HMAC (crack with jwt_tool+rockyou), `kid` injection, RS256→HS256 confusion.
- **XXE** — `<!ENTITY x SYSTEM "file:///flag">`; OOB/param XXE when blind.
- **Deserialization** — PHP `unserialize`, Python `pickle`, Java/ysoserial, Node `node-serialize`.
- **Prototype pollution (Node)** — `__proto__` in the JSON body → RCE/auth-bypass gadget.
- **Race condition** — limit overrun (coupon/balance/one-time token), fire N parallel requests.
