## SCOPE (read first)

## TOOLBOX (in the sandbox)
pwntools · gdb+pwndbg/gef · checksec · ROPgadget/ropper · one_gadget · libc-database · patchelf

## TRIAGE (mandatory)
```bash
file ./chal && checksec ./chal      # RELRO, Canary, NX, PIE, libc?
strings ./chal | grep -iE "flag|/bin/sh|system|win"
nm -C ./chal 2>/dev/null | grep -iE "win|backdoor|shell"   # ret2win?
```
Decision tree from checksec:
- No canary + NX + a `win()` → **ret2win** (simplest).
- No canary + NX, no win, libc provided → leak libc, **ret2libc / one_gadget**.
- PIE on → need an address leak first (format string / partial overwrite).
- Heavy malloc/free menu → **heap track**.

Offset: `cyclic 200` → crash → `cyclic -l <value>`.

## EXPLOIT TRACKS
- **ret2win** — overflow into saved RIP → `win()` addr. Keep alignment (add a `ret` gadget if `movaps` segfaults).
- **ret2libc** — leak GOT via puts/printf → identify libc (libc-database) → compute `system`/`/bin/sh` → ROP. Or `one_gadget`.
- **format string** — `%n` write into GOT, `%N$p` leak. pwntools `fmtstr_payload(offset, {addr:value})`.
- **heap** — tcache poisoning, double-free, fastbin dup, unsorted-bin leak; `__free_hook`/`__malloc_hook` (old libc) or FSOP/`_IO_2_1_stdout_` (new libc). Record chunk sizes + free order in `findings.json`.
