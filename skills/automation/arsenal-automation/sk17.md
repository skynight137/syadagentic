"Premium-feel" features that make the agent feel like it thinks, plans, and runs on its own. Everything that touches funds STILL goes through the governor; the things that drive execution (planner/swarm/automation/skill_forge) go into FROZEN_PATHS.

| Feature | Script | Core |
|---|---|---|
| Workflow planner | `scripts/planner.py` | NL goal → multi-step plan → staged execution (gated) |
| Multi-agent swarm | `scripts/swarm.py` | parallel specialist lanes + key separation |
| Skill forge | `scripts/skill_forge.py` | agent drafts a new skill → proposal (no auto-apply) |
| Automation engine | `scripts/automation.py` | WHEN trigger THEN actions |

| Voice mode | `scripts/voice.py` | STT→LLM→TTS, talk to it like a phone call |
| Explainability | `scripts/explain.py` | summarise the audit trail "what & why" |

## 1. Workflow planner (Tier 1)

```python
from planner import make_plan, execute_plan
plan = make_plan("fill base then buy token 0xABC on 5 wallets")   # LLM via model_registry
print(plan.summary())                                            # step 💸 = touches funds
await execute_plan(plan, handlers, confirm_cb)                   # checkpoint + gated
```

The agent decomposes the goal into steps from the skill library, each fund step goes through a governor-gated handler. The plan is shown before it runs.

## 2. Multi-agent swarm (Tier 1)

```python
from swarm import Swarm, Specialist
sw = Swarm([Specialist("researcher", researcher_fn),
            Specialist("monitor", monitor_fn),
            Specialist("executor", executor_fn, holds_keys=True)])
await sw.dispatch({"researcher": {...}, "monitor": {...}})   # PARALLEL
sw.safety_report()   # warns if a non-executor lane holds keys
```

Key separation: watcher/monitor lanes (always online) **do not hold keys**; only the executor signs.

## 4. Automation engine (Tier 3)

```python
from automation import AutomationEngine
ae = AutomationEngine()
ae.add_rule("gas cheap → swap", "price", {"metric": "gas"},
            actions=[{"action": "swap", "params": {...}, "funds": True}])
await ae.fire(event, action_handlers, confirm_cb)   # fund action → governor
```

IFTTT for crypto/ops: trigger (webhook/schedule/price/onchain_event/custom) → action chain.

Test a strategy on historical data before going live. Not a prediction — a validation tool.

## Notes

- Planner/skill-forge/swarm decomposition use an LLM via `model_registry` (sk7/v4.0) — `add model` first if the cascade is empty.
